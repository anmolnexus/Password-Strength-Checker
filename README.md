# Password Strength Checker 🔐

This is my first Python project, which I built while learning programming and exploring cybersecurity.

The program checks a password and gives an idea of its strength based on different conditions.

## What I Learned
- Working with Python strings.
- Using conditional statements.
- Applying basic password validation.
- Understanding password security.

## Technologies Used
- Python
- Visual Studio Code
- GitHub

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/anmolnexus/Password-Strength-Checker.git
```

2. Open the project folder in VS Code.

3. Run the program:

```bash
python password_checker.py
```

I created this project to improve my Python skills and understand how basic password checking works. It is a small step in my journey of learning cybersecurity.
